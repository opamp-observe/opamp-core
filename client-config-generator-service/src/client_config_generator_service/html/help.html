Client Config Generator Help

Guide to generating schema-validated OpAMP consumer configuration files.

Back to generator opamp.info

What it creates

The generator creates JSON configuration files for the OpAMP consumer. Form controls, defaults, required fields, and validation are supplied by the packaged consumer JSON Schema.

Supervisor and Observer

Supervisor starts and manages the agent, so the agent configuration path and launch parameters are available. Observer attaches to an externally managed process and requires a process-detection regular expression.

Load, validate, and save

  1. Select an existing JSON file and choose Load selected, or start with schema defaults.
  2. Choose a deployment mode and complete the displayed fields.
  3. Choose Validate to review schema errors.
  4. Enter a relative .json name and choose Save.

Files are limited to the configured storage directory. Parent-directory traversal and non-JSON targets are rejected. When the service is read-only, loading remains available and saving is disabled.

Deployment

When embedded, the feature appears only when its Quart entry point is enabled in component-entry-points.quart. Standalone deployments use the same UI and API at port 8095 by default. Host or deployment-managed authentication applies when provider authentication is available.

API

The versioned API exposes schema, list, load, validation, and save operations below /client-config-generator-service/api/v1.
